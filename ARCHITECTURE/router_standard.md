# SecretTalk — Router Standard

## 1. Назначение

Router является единой точкой маршрутизации пользовательских действий.

Router не содержит бизнес-логику модулей.

## 2. Основная ответственность

Router определяет:

- какой пользовательский режим активен;
- какой модуль должен получить сообщение;
- какой экран должен быть показан;
- когда пользователь выходит из режима;
- какой маршрут является единственным активным.

## 3. Стандарт маршрута

Каждая пользовательская функция должна иметь:

`ENTRYPOINT → ROUTER → MODULE`

Router передаёт управление модулю.

Модуль выполняет бизнес-логику.

## 4. Запрет прямого обхода Router

User-facing модуль не должен самостоятельно перехватывать глобальные сообщения, если пользовательский маршрут должен контролироваться Router.

## 5. Состояние

Если модуль является stateful, Router проверяет состояние пользователя до передачи сообщения.

Пример:

`main → aida`

Только после входа в `aida`:

`message → Router → AiDa`

После выхода:

`message → Router → другой маршрут`

## 6. Уникальность

Одна команда, кнопка или пользовательское действие имеет одного владельца.

Запрещены:

- два активных маршрута;
- два активных обработчика одной команды;
- последовательная передача одного сообщения нескольким модулям;
- старый обработчик после миграции.

## 7. Menu

Menu предоставляет пользовательскую точку входа.

Menu не определяет бизнес-логику модуля.

Связь:

`MENU → ROUTER → MODULE`

## 8. Index

Index не заменяет Router.

Если модуль уже управляется Router, Index не должен повторно маршрутизировать его сообщения.

Index отвечает только за запуск и root-level orchestration.

## 9. Интеграция

Новый маршрут подключается по стандарту:

1. определить entrypoint;
2. определить module owner;
3. добавить route;
4. подключить Menu при необходимости;
5. проверить state;
6. проверить полный user flow;
7. удалить старый route;
8. проверить отсутствие дублирования.

## 10. Критерий готовности

Router считается корректным, если для каждого пользовательского действия однозначно определена цепочка:

`USER ACTION → ROUTER → ONE MODULE → RESULT`

## 11. Главное правило

Router маршрутизирует.

Module выполняет.

Menu предоставляет вход.

Index запускает.

Ни один слой не должен выполнять ответственность другого слоя.
