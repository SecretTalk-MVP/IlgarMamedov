# SecretTalk Admin Module

Version: 1.0

## Назначение

Модуль Admin управляет всеми административными возможностями проекта SecretTalk.

## Цели

- отделить административную логику от index.js;
- обеспечить безопасное управление системой;
- сделать код модульным и расширяемым;
- упростить сопровождение проекта.

## Состав модуля

- index.js — точка входа модуля;
- permissions.js — проверка прав администратора.

В дальнейшем будут добавлены:

- menu.js
- statistics.js
- users.js
- moderation.js
- broadcast.js
- archive.js

## Правило

Вся новая административная логика создаётся внутри этого модуля.

Добавление новой логики в index.js не допускается.
