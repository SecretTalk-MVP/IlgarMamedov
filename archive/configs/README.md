# Configs Archive

Назначение

В этой папке хранятся архивные копии файлов конфигурации проекта SecretTalk.

Цель

- сохранение рабочих конфигураций;
- быстрое восстановление настроек;
- отслеживание изменений;
- защита от потери важных параметров.

Правила

1. Перед изменением любого конфигурационного файла сохранить его копию.
2. После успешного изменения сохранить новую версию.
3. Архивные копии после сохранения не изменяются.

Примеры

config_2026-08-02_before_update.js
config_2026-08-02_after_update.js
.env.example
