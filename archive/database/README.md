# Database Archive

Назначение

В этой папке хранятся архивные копии структуры базы данных проекта SecretTalk.

Цель

- сохранение структуры базы данных;
- возможность быстрого восстановления;
- отслеживание изменений схемы;
- хранение важных миграций.

Правила

1. Перед изменением структуры базы данных сохранить её копию.
2. После успешной миграции сохранить новую версию.
3. Архивные файлы после сохранения не изменяются.

Примеры

schema_2026-08-02_before_update.sql
schema_2026-08-02_after_update.sql
