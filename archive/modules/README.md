# Modules Archive

Назначение

В этой папке хранятся архивные копии папки modules.

Цель

- сохранение рабочих модулей;
- быстрый откат отдельных модулей;
- сравнение версий;
- восстановление после неудачного рефакторинга.

Правила

1. Перед переносом или серьёзной переработкой любого модуля сохранить его копию.
2. После успешного завершения работ сохранить новую версию.
3. Архивные копии не изменяются.

Рекомендуемый формат

admin_2026-07-31_before_refactor/
admin_2026-07-31_after_refactor/
search_2026-08-02_before_update/
