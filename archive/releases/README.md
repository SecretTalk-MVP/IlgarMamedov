# Releases

В этой папке хранятся стабильные версии проекта SecretTalk.

Правила:

- Каждая версия хранится в отдельной папке.
- Перед любым крупным изменением создаётся архив текущего состояния.
- После успешного завершения крупного этапа создаётся новый архив.
- Архивы не изменяются после создания.

Пример:

MVP_0.3_Before_Admin/
MVP_0.3_After_Admin/
MVP_0.4_Before_Search/
