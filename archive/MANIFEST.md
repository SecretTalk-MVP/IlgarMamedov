# SecretTalk Archive

Version: 1.0

## Назначение

Архив является системой хранения истории развития проекта SecretTalk.

Главная цель архива — обеспечить безопасную разработку, возможность быстрого восстановления и сохранение истории принятых решений.

---

## Структура архива

- releases — стабильные версии проекта
- index — архив файла index.js
- modules — архив отдельных модулей
- database — архив структуры базы данных
- configs — архив конфигурационных файлов
- notes — документация, идеи и история развития

---

## Правила

1. Перед каждым крупным изменением создаётся архив.
2. После успешного завершения этапа создаётся новый архив.
3. Архивные файлы никогда не изменяются.
4. Любое изменение проекта должно иметь возможность отката.

---

## Философия

Мы создаём не только код.

Мы сохраняем историю рождения SecretTalk.

Каждый архив — это часть истории проекта.
