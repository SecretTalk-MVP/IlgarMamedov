# Index Archive

Назначение

В этой папке хранятся архивные копии файла `index.js`.

Цель

- возможность быстрого отката;
- сравнение версий;
- анализ изменений;
- восстановление рабочего состояния проекта.

Правила

1. Перед каждым крупным изменением сохранить текущий `index.js`.
2. После успешного завершения этапа сохранить новую версию.
3. Архивные файлы после сохранения не изменяются.

Формат имени файла

index_YYYY-MM-DD_описание.js

Примеры

index_2026-07-31_before_admin.js
index_2026-07-31_after_admin.js
index_2026-08-02_before_search.js
