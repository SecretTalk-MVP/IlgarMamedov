# Notes Archive

Назначение

В этой папке хранятся заметки, решения, идеи и история развития проекта SecretTalk.

Цель

- сохранять важные архитектурные решения;
- фиксировать идеи для будущих версий;
- вести журнал изменений;
- документировать найденные ошибки и способы их решения.

Правила

1. Каждая заметка должна иметь понятное название.
2. Важные решения не удаляются, а дополняются.
3. История проекта должна сохраняться для будущих разработчиков.

AIDA_PERSONALITY.md
MEMORY_ENGINE.md
CHANGELOG.md
BUGS.md
ROADMAP.md
